# Contributing

Thanks for your interest in contributing to this Godot project template.

This project is meant to remain a simple, developer-friendly baseline for future work. Contributions should keep the project organized, easy to understand, and useful as a foundation for new game development work.

## How to Contribute

You can contribute by:

- reporting bugs or issues
- suggesting improvements to structure or tooling
- improving documentation
- adding reusable systems or templates
- refactoring code for clarity and maintainability
- improving quality-of-life features for project setup

## Before You Start

- Keep the project scope in mind: this is a baseline template, not a full game.
- Favor simple, readable, maintainable code.
- Match the project’s existing structure and naming patterns where possible.
- Keep features modular and easy to remove or extend.

## Pull Request Guidelines

When opening a pull request:

1. Keep the scope focused and specific.
2. Include a clear summary of what changed and why.
3. Mention any setup requirements, configuration changes, or compatibility issues.
4. Update documentation if the change affects setup, workflow, or project structure.
5. Ensure the project still loads in Godot and does not introduce obvious regressions.

## Code Style

- Prefer readable, explicit GDScript.
- Keep scripts organized by responsibility.
- Use clear naming for scenes, scripts, and folders.
- Avoid introducing unnecessary dependencies or complexity.
- Favor maintainability over cleverness.

## Reporting Issues

When reporting a problem, include:

- a short description of the issue
- the expected behavior
- the actual behavior
- reproduction steps if relevant
- the Godot version used
- screenshots or logs when helpful

## Community Expectations

Please be respectful, constructive, and collaborative. This project aims to maintain a welcoming development environment.

## Code of Conduct

This project follows the Contributor Covenant Code of Conduct. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the policy.
